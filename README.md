# חיות עידן הקרח

יישומון PWA בעברית עם מבוא, עשרה עמודי בעלי חיים, פירוק שמות ועמוד מקורות. תמונות המקור נוצרו עבור הפרויקט; האתר משתמש בקובצי WebP מותאמים.

## הרצה

```bash
npm test
npm run build
```

יש להגיש את התיקייה `dist` כאתר סטטי. הגדרת `vercel.json` בונה ומגישה אותה ב־Vercel. לכל עמוד בעל חיים כתובת עצמאית `/animal/<slug>`.
